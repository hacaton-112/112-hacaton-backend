# Отчёты преподавателя и экспорт

## Доступ

Маршруты доступны ролям `instructor` и `admin`. Преподаватель получает только
попытки по своим назначениям и группам. Администратор может строить отчёты по
всем данным. Экспорт фиксируется в `audit_log` как
`instructor.report.exported`; содержимое отчёта в журнал не записывается.

## JSON-отчёт

`GET /api/v1/instructor/reports`

Отчёт по группе:

```text
?scope=group&groupId=<uuid>&from=2026-09-01T00:00:00.000Z&to=2026-09-30T23:59:59.999Z
```

Отчёт по ученику:

```text
?scope=student&operatorId=<uuid>&from=2026-09-01T00:00:00.000Z&to=2026-09-30T23:59:59.999Z
```

`from` и `to` необязательны и включают граничные значения. Начало периода не
может быть позже конца (`REPORT_INVALID_PERIOD`). Один отчёт ограничен 500
попытками; для большего набора API возвращает `REPORT_TOO_LARGE` и требует
сузить период. Это защищает целевой норматив формирования отчёта до 30 секунд.

Ответ содержит:

- общие числа попыток, завершений, оценок и сдач;
- процент сдачи, средний и лучший балл;
- среднее время ответа и разговора;
- сводку по каждому ученику для группового отчёта;
- строки попыток с назначением, сценарием, статусом и нормативом;
- количество пропущенных критических вопросов, обязательных и некорректных
  полей, а также рекомендации из детерминированного debrief.

Пока grammar check не влит в `main`, поле `grammar.status` равно
`unavailable`. Отчёт не подменяет отсутствующий результат пустым списком.

## Экспорт

`GET /api/v1/instructor/reports/export` принимает те же параметры и
обязательный `format=csv|xlsx|pdf`.

- CSV кодируется в UTF-8 с BOM и разделителем `;`.
- XLSX содержит листы `Сводка`, `Ученики` и `Попытки`.
- PDF использует встроенный Noto Sans с поддержкой кириллицы.

Все форматы строятся из одного и того же снимка отчёта и возвращаются как
attachment с безопасным именем файла. Пустой набор является корректным отчётом
и экспортируется во всех трёх форматах.
