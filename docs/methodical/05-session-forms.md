## 4. Индивидуальный план коррекции

| Навык     | Наблюдаемая проблема | Упражнение | Критерий улучшения | Срок |
| --------- | -------------------- | ---------- | ------------------ | ---- |
| Опрос     |                      |            |                    |      |
| Карточка  |                      |            |                    |      |
| Службы    |                      |            |                    |      |
| Регламент |                      |            |                    |      |
| ДДС       |                      |            |                    |      |

На одну повторную попытку выбирают не более трёх приоритетных коррекций.
Критерий улучшения должен быть наблюдаемым: например, «все критические вопросы
закрыты до сохранения», а не «быть внимательнее».
