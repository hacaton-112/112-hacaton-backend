# Архитектура

Система разделена на основной учебный контур и съёмные речевые/телефонные компоненты. Поэтому сбой или отключение ASR, TTS, языковой модели и Asterisk не блокирует ДДС, управление занятиями и отчёты.

## Компоненты и границы

| Компонент | Ответственность | Граница |
| --- | --- | --- |
| Веб-клиент `trainer-client` | Экраны ролей, рабочие места 112/ДДС, карта, отчёты. | Не считает баллы и дедлайны; показывает данные сервера. |
| Backend NestJS | Права, учебные сценарии, назначения, занятия, машины состояний, оценка, отчёты, REST/WebSocket. | Единственный авторитет для времени, баллов и переходов. |
| PostgreSQL 17 | Учётные записи, каталог в версиях, попытки, карточки, отчётные данные, аудит. | Доступен backend; снаружи порт привязан к localhost. |
| ASR | Потоково превращает русскую речь в текст; VAD отделяет речевые участки. | Локальный HTTP на CPU, без своей авторизации; наружу не публикуется. |
| Диалоговая модель `local-llm` | Формирует реплику учебного заявителя в рамках сценария. | Сменяемая GGUF-модель за `llama-server`; бизнес-переходы не решает. |
| Модель инструментальных задач `tools-llm` | Возвращает строго структурированные ответы для классификации, фоновых и методических задач. | Выход проверяется Zod-схемой; модель можно заменить. |
| TTS `piper-tts` | Синтезирует аудио из текста реплики. | CPU-сервис; опционально заменяется CUDA-синтезом. |
| Офлайн-карта | TileServer GL раздаёт стили, шрифты и MBTiles; MapLibre показывает их в браузере. | Не обращается к внешним картографическим сервисам после подготовки образа. |
| MinIO | Хранит WAV-сегменты и manifest звонка, если запись включена. | Порты на localhost; клиент получает аудио через backend. |
| Gateway NGINX | Единая HTTPS-точка для клиента, REST, WebSocket и карты. | Завершает TLS 1.2/1.3; backend не публикует порт на хост. |
| Asterisk | Учебная SIP/WebRTC-телефония и передача вызова бригаде. | Опциональный контур; для занятия ДДС не нужен. |

## Связи

```text
Браузер -> HTTPS gateway -> REST/WebSocket backend -> PostgreSQL
                                      |-> MinIO (только записи)
                                      |-> ASR -> текст
                                      |-> dialogue LLM -> реплика -> TTS
                                      |-> tools LLM -> JSON -> проверка Zod
Браузер -> HTTPS gateway -> TileServer (локальные тайлы)
Браузер <-> gateway <-> Asterisk (только телефония)
```

Модели не имеют прямого доступа к базе и не меняют состояние учебного процесса. Все команды проходят через backend, где проверяются роль, схема, текущее состояние и идемпотентность.
