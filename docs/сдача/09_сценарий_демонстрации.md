# Порядок показа

Рассчитано на пять минут. Готовится заранее, во время выступления ничего не
генерируется: модель на процессоре отвечает десятки секунд, и живая генерация
выглядит зависанием.

## Подготовка за час до защиты

1. Проверить, что стенд отвечает: страница открывается, backend и gateway
   здоровы.
2. Наполнить демонстрационные данные:

   ```bash
   bun run prepare:demo
   ```

   Скрипт подтверждает эталоны, проводит три занятия в разные дни, доводит одно
   назначение до зачёта и печатает ссылки. Работает несколько минут: он ждёт
   оценку текста и выводы по группе.
3. Открыть заранее во вкладках: отчёт последнего занятия, страницу «Отчёты»,
   карточку обучающегося, «Карточки ДДС» под учётной записью диспетчера.
4. Один раз нажать `Ctrl+Shift+R`, чтобы браузер взял свежую сборку.

Учётные записи показа: `dds-demo-instructor@example.test` и
`dds-demo-01…03@example.test`, пароль `Demo112!`.

Убрать данные после защиты: `bun run demo:reset`.

## Ход показа

| Шаг | Кто на экране | Что делаем | Что говорим |
| --- | --- | --- | --- |
| 1 | Преподаватель, «Учебные сценарии» | Показать каталог, открыть строку вызова из билета | 94 экзаменационных вызова уже в системе; новый можно написать вручную или заказать у ИИ |
| 2 | Преподаватель, «Мониторинг» → «Занятия ДДС» | Показать созданное занятие и его состав | Занятие раздаёт карточки группе по категориям, норматив первичного статуса — 30 секунд |
| 3 | Диспетчер, «Карточки ДДС» | Принять карточку, пройти по статусам до завершения работ | Это регламент из памятки: приём, выезд, прибытие, работы, завершение; комментарии обязательны |
| 4 | Преподаватель, мониторинг | Показать, что статус изменился без перезагрузки | Преподаватель видит смену в реальном времени |
| 5 | Преподаватель, отчёт занятия | Открыть разбор карточки: время против норматива, покрытие пунктов эталона, ошибки, балл | Оценка складывается из процесса, текста и грамотности; эталон утверждает преподаватель |
| 6 | Тот же отчёт | Показать выводы ИИ по группе и скачать PDF | Выводы считаются по обезличенной статистике, отчёт выгружается в PDF, XLSX и CSV |
| 7 | Преподаватель, «Отчёты» | Показать аналитику: слабые места, частые ошибки, динамику | Видно, чему учить группу дальше |
| 8 | Преподаватель, карточка ученика | Показать прогноз готовности и точность прогноза | Точность считается на попытках, которых модель не видела; при нехватке данных так и написано |
| 9 | Любая роль, карта | Открыть карту происшествия | Карта своя, Москва и область, интернет не нужен |

## Если что-то пошло не так

- **Пустой отчёт или аналитика.** Данные показа не подготовлены — запустить
  `bun run prepare:demo` заново.
- **«Готовятся» вместо выводов ИИ.** Модель ещё считает; продолжить рассказ и
  вернуться к слайду через минуту.
- **Чёрная карта.** Открытая вкладка держит старую сборку — `Ctrl+Shift+R`.
- **Недоступен сервер.** Показывать записанный ролик или локальный запуск на
  ноутбуке: контур поднимается тем же `docker compose`.

## О чём не говорить как о готовом

- Передача наряда по телефону: Asterisk на стенде не запущен.
- Качество распознавания и синтеза на независимой выборке не измерялось.
- Нагрузочные испытания на целевом железе не проводились.
