## Команды управления базой данных (Backend)

```bash
# Полный сброс и перезаливка чистого сида (очистка + админ + классификатор + сценарии + группы/назначения)
bun run db:reset

# Только очистка всех таблиц (каскадно)
bun run db:clean

# Стандартный сид (без удаления существующих записей)
bun run db:seed
```
